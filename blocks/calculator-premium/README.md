# calculator-premium

Custom **calculator** block. Purpose: interactive-calculator.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Estimated monthly premium calculator card (STUB). One row per item, cells [type | label/content | value] where type is heading, result, input, disclaimer or cta: heading + result range, N input rows (label + default value, rendered with a disabled placeholder slider), disclaimer, CTA link.
