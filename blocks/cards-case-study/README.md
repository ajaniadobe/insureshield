# cards-case-study

Custom **cards** block. Purpose: testimonial.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 3 story cards in a connected bordered grid: image area (placeholder when empty), H3 linked title, description, 'Read more' link. One row per card: [image | <h3><a>title</a></h3><p>description</p><p><a>Read more</a></p>].

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
