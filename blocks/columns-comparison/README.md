# columns-comparison

Custom **columns** block. Purpose: comparison.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 3x5 bordered comparison grid. Header row [<h2>title</h2> | <h3>option A</h3> | <h3>option B</h3>], then one row per topic [<img> + <h3>topic</h3> | option A text | option B text]; last column gets a check-circle icon, mobile shows header labels per cell.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
