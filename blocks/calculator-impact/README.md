# calculator-impact

Custom **calculator** block. Purpose: interactive-calculator.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Business impact calculator (STUB), bordered two-pane panel. One row per item, cells [type | label/content | value] where type is intro, input, result, legend, summary, disclaimer or cta: left pane intro + input rows (label + default value, disabled placeholder slider); right pane results (first is the headline), legend, summary, disclaimer, CTA link + note. Cube visualisation is generated by code, not authored.

## Supported variations

No variations.

- Content fields derived from the block's decorate contract.
